# 유사한 단어 찾기 게임<br>

사전 학습된 모델 또는 적절한 데이터셋을 찾는다.

워드 임베딩 모델을 학습시킨다.

단어 유사도가 0.8 이상인 A, B를 랜덤 추출한다.

A, B와 대응되는 C를 추출한다.

D를 입력 받는다.

=> A:B = C:D 관계에 대응하는 D를 찾는 게임을 만든다.
(예시: A: 산, B: 바다, C: 나무, D: 물)

<출력 예시>

관계 [ 수긍 : 추락 = 대사관 : ? ]
모델이 예측한 가장 적합한 단어: 잠입
당신의 답변과 모델 예측의 유사도: 0.34
아쉽네요. 더 생각해보세요.

<br />

### ▶️ 사용 데이터 설명

[KLUE (Korean Language Understanding Evaluation)]

출처 : Hugging Face Datasets (https://huggingface.co/datasets/klue/klue
)

수집 방법 : KLUE 연구팀에서 한국어 텍스트를 기반으로 구축 후 공개, Hugging Face Hub에서 다운로드 가능

데이터 출처 및 범위

수집 데이터 기간 : 2020년 ~ 2021년 (NeurIPS 2021 공개 시점 기준)

데이터 범위 : 한국어 자연어 이해(NLU) 벤치마크를 위한 8개 태스크(주제 분류, 의미 유사도, 자연어 추론, 개체명 인식, 관계 추출, 의존 구문 분석, 기계 독해, 대화 상태 추적)

주요 변수 : 문장 텍스트, 문장 쌍, 레이블(주제, 유사도 점수, 추론 관계, 개체명 태그, 관계 유형, 문법 의존 관계, 독해 정답 span, 대화 상태 등)

<br />

### 대응 기준
- C는 A와 코사인 유사도가 가장 높은 단어를 기준으로 선택하였다.

- 대응 기준은 워드 임베딩 벡터 간 코사인 유사도 최댓값이다.

- 즉, A와 의미적으로 가장 가까운 단어를 C로 대응시킨다.
